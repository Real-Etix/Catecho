# Catecho belly token bot

The user approved the three-pose cream robot concept and requested implementation, with a vertical chrome antenna at the exact top centre, two telescoping antenna arms and white gloves holding an expanding belly screen.

The bot replaces the existing antenna-side token preview when Codex monitoring and edge preview are enabled. Without the preview, the existing antenna remains. The full radio remains available through the top antenna. The base moves the widget; the belly and gloves toggle its dashboard. A horizontal pull also expands/retracts it. Compact mode keeps a live reading visible. Expanded mode shows the selected chat, time window and coverage status using the existing local monitor.

Classic uses cream molded plastic, sage e-paper, metal joints and softly shaded gloves. Flat retains the same silhouette and controls with outlines. English, Simplified Chinese and Traditional Chinese are supported. No idle movement, new network service, or additional usage collection is introduced.

The expansion is one interruptible 280 ms motion driving screen width, arms, gloves and inward body movement together. The native window reserves space before opening and releases it after closing. Both desktop edges, saved positions, multiple displays and Reduce Motion must work. Escape retracts an open belly before tucking a full radio. Tucking the full radio resets to the compact bot.

Verification: geometry and gesture regression checks, native panel smoke checks, real SwiftUI renderings of both appearances and all languages, then isolated GUI interaction before local installation. Preserve user preferences and cached data.
