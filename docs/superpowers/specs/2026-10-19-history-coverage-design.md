A streaming JSON projection extracts the existing numeric/identity fields from large records while discarding conversation payloads without retaining them. Non-usage content must not create a partial-history warning merely for exceeding the old line limit. Corrupt/truncated compression, malformed relevant metadata, unsupported compression, and genuinely missing usage remain explicit. No invented estimates. Existing response IDs/cumulative signatures deduplicate plain/archive/compressed copies.

Prefer plain `.jsonl` when a compressed sibling exists; support historical compressed-only files. Compressed input and decompressed output have separate per-poll budgets. Limit active decoder contexts and decompression windows to bound memory; continue streams across polls and release at EOF. No raw decompressed file is written to disk.
